# Security Policy

## Supported Versions

This project is a repository of prompt definitions and documentation. It has no supported release versions.

## Reporting a Vulnerability

This repository contains no application code and processes no user data. It has no defined vulnerability scope.

If you find a problem in the workflow definitions, open an issue or a pull request.

If you believe the content causes a security risk for users, open an issue and mark it as sensitive. Do not include credentials or private data.
